# CompassVPN — комплект для проверки

Учебный стенд: четыре варианта подключения, Xray, 3x-ui, Prometheus и Grafana. Дата отчёта: **27 октября 2026**.

Начните с [итогового отчёта](docs/REPORT.md), затем откройте [инструкцию эксплуатации](docs/OPERATIONS.md). [Готовый HTML-отчёт](docs/REPORT.html) можно скачать и открыть браузером.

## Что подтверждено

- Три отдельных профиля панели успешно выполнили запрос внешнего IP через тестовый SOCKS-клиент на ПК.
- Пользователь подтвердил работу первых трёх вариантов на Android по Wi-Fi.
- Мобильное подключение Билайн остаётся нерешённым; четвёртый вариант дал TCP timeout.
- На VPS запущены Xray, 3x-ui и мониторинг. Сетевые метрики node-exporter сейчас относятся к контейнеру.
- Четвёртый вариант — контроль того же REALITY/Vision на TCP 443, а не четвёртый независимый протокол.

## Файлы

- `site.yml` — исходный Xray/VLESS/REALITY на 443; существующий config сохраняется, новые ключи создаются только при его отсутствии.
- `monitoring.yml` — воспроизводит установленный стек мониторинга с указанным в отчёте ограничением сетевой метрики.
- `subscriptions.yml` — обслуживание **уже установленной** панели и сертификата; вызывает два Python-скрипта. При выполнении кратко перезапускает панель.
- `create_test_inbounds.py` — добавляет отсутствующие профили 01–03, сохраняет существующие.
- `publish_subscriptions.py` — настройки HTTPS-подписок и таймер сертификата; резервная копия БД перед изменением.
- `discover.yml`, `discover_report.yml` — инвентаризация VPS.
- `report.yml` — свежий HTML/JSON отчёт по серверу. Не выполняет клиентские leak-тесты.
- `Test-VpnSubscriptions.ps1` — отдельный SOCKS-тест через ядро Happ; URL передаются параметром `-Links`.
- `Open-CompassVPN.ps1`, `Get-VpnReport.ps1` — доступ к панелям и получение отчёта.
- `collect_access.py` — экспорт текущих доступов; вывод **секретный**, перенаправлять только в локальную папку `private/`.
- `evidence/` — результаты измерений без ключей и ссылок подписок.

## Границы воспроизводимости

Playbook рассчитаны на Ubuntu, Ansible 2.20 и запуск локально на VPS от sudo. Это комплект существующего стенда: создание виртуальной машины, SSH-доступ, первичная инициализация 3x-ui и выдача IP-сертификата описаны отдельно и не объединены в установку «одной кнопкой». Все адреса и порты относятся к этому стенду.

Исправленные playbook публикации не применялись повторно к VPN для сдачи отчёта. Синтаксис проверен отдельно; это не подтверждение развёртывания с нуля. Версии образов зафиксированы по установленному стенду, актуальность исправлений безопасности не оценивалась.

## Доступы

Файл `private/ACCESS.txt` находится только на компьютере владельца, в GitHub его нет. Пароли, URL подписок, БД, журналы клиента и SSH-ключи не входят в репозиторий. Проверяющему доступы передаются отдельно. Раскрытые ранее в переписке ключи/пароли следует заменить перед постоянной эксплуатацией, с обновлением клиентских профилей.
