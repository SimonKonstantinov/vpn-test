Как понимать результат

active означает, что процесс службы запущен. HTTP 200 означает ответ сайта с VPS. HTTP -1 означает ошибку соединения; другие коды требуют анализа. Эти проверки не подтверждают работу VPN на телефоне.

Утечки DNS, IPv6, WebRTC, доступность через Билайн и скорость клиента здесь не проверяются. Сетевые метрики текущего node-exporter относятся к контейнеру, а не ко всему VPS.
