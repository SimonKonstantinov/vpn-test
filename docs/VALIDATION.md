# Проверки комплекта

Дата: 27 октября 2026.

- Ansible 2.20 на VPS: `--syntax-check` для всех шести playbook — успешно.
- `report.yml` выполнен на действующем сервере: `ok=13 changed=2 failed=0 unreachable=0`. Изменения — два файла отчёта; VPN-службы не перезапускались.
- Python: компиляция `create_test_inbounds.py`, `publish_subscriptions.py` — успешно. Сами изменяющие состояние скрипты повторно не запускались.
- PowerShell: синтаксический анализ трёх `.ps1` штатным Parser — успешно. Скрипты открытия туннеля и скачивания отчёта не запускались автоматически, чтобы не оставлять дополнительный туннель и не менять Downloads.
- Локальный JSON прежнего SOCKS-теста включён в evidence. Число TCP timeouts в предоставленном журнале повторно подсчитано: 16.
- Git: публикация по явному списку исходников; private/, SSH-ключи, реальные ссылки подписок и сырые журналы исключены. Перед push содержимое индекса сравнивается с известными секретами из локального файла доступов.

Не выполнялись: полный ansible-lint/Checkov/Molecule, установка на чистый VPS, проверка идемпотентности deployment-playbook, повторные клиентские сетевые тесты. Эти этапы не входят в подтверждённые результаты. Проверка синтаксиса не заменяет функциональное испытание. Зависимости полного lint-набора локально отсутствуют; выполнены доступные проверки средствами действующего VPS и PowerShell.

Повторение синтаксической проверки на Linux:

```bash
ansible-playbook --syntax-check -i localhost, -c local site.yml monitoring.yml report.yml discover.yml discover_report.yml subscriptions.yml
python3 -m py_compile create_test_inbounds.py publish_subscriptions.py collect_access.py scripts/build_report.py
```

Для расширенной проверки в отдельном окружении установите ansible-lint и выполните `ansible-lint *.yml`; затем проверьте развёртывание на отдельном тестовом VPS. Не запускать full deploy на действующем сервере только ради проверки синтаксиса.
